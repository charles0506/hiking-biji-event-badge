# 健行筆記 活動/寶石任務提示（userscript）

站台：`https://hiking.biji.co/*`

## 功能

1. **活動徽章**：步道詳細頁 / 任何頁面上的步道卡片（含 GPX 軌跡頁裡內文引用的步道連結），只要那條路線屬於某個線上活動（寶石任務、尋寶集章、健走趣…），標題旁自動貼綠色（進行中）/灰色（未開始、已結束）/藍色（長期）徽章，滑鼠移上去看活動期間，點徽章直接開那條步道自己的頁面（不用往下滑找）。
2. **沿途任務路線**：像「陽明山東西大縱走」這種跨多個行政區的長路線，步道頁/GPX 軌跡頁會多一個可收合面板「🔍 沿途 GPX 軌跡比對，這些任務路線也在路上」，列出實際用官方 GPX 軌跡點算過、真的路過的其他任務路線（見下方「沿途任務路線怎麼算的」）。
3. **附近任務**（右下角「📍 附近任務」按鈕）：按下用瀏覽器定位取得目前縣市，直接列出該縣市**進行中**的活動路線清單，點了開新分頁。定位只在本機比對縣市中心點座標，不外送。定位失敗會顯示上次記住的縣市。

## 安裝

Tampermonkey / Violentmonkey 匯入 `biji-event-badge.user.js`。

## 索引怎麼來的

repo 根目錄（`../` 相對這個檔案）底下：

1. `build_index.py` — 爬 `hiking.biji.co` 的活動列表（含分頁與 `category=theme`）與每個活動專區頁（含子頁籤 `nav=`），解析頁面裡的 `<ul id="trail_list">`，產出 `events.json`（活動清單）與 `trails.json`（路線→活動反查表）。
2. `build_overlap.py` — 找出 `trails.json` 裡跨 2 個以上行政區的「長路線」，抓它們自己與候選步道的**官方 GPX**，用軌跡點實際距離（250 公尺內）算是否真的路過，取代單純比對行政區名稱（噪音很大，同區但沒真的路過的健走趣打卡點也會混進來）。有快取（`trail_gpx_cache.json`），中斷重跑不會整個重來。輸出 `overlap.json`。
3. `gen_userscript.py` — 讀 `events.json` / `trails.json` / `overlap.json`，壓成 `EV`（活動陣列）/ `T`（trailId → [名稱,縣市,連結,[活動索引]]）/ `OV`（長路線trailId → GPX確認過的候選trailId清單），貼進 `userscript.tpl.js` 模板，輸出成這支 `biji-event-badge.user.js`，`@version` 自動 +1。
4. `lookup.py` — 純命令列查詢用（不影響 userscript），例：
   ```bash
   python lookup.py 大屯山
   python lookup.py --events
   ```

## 多久要重跑一次

健行筆記活動會換季（例如「2026臺北健走趣」「花蓮山海騎遇記」），新活動上線或路線異動時，重跑：

```bash
cd ..
python build_index.py
python build_overlap.py
python gen_userscript.py
```

`build_index.py` 只重抓活動清單本身，`build_overlap.py` 有快取，只會處理 `overlap.json` 裡還沒出現的路線，通常不用整份重跑；只跑 `gen_userscript.py` 也可以（沒有新的 GPX 精算結果，但 EV/T 索引會更新）。重跑完到 Tampermonkey 重新匯入這支 `.user.js`（`@version` 已自動升號，會被認成新版本更新）。

## 沿途任務路線怎麼算的

1. 從 `trails.json` 抓出「跨 2 個以上行政區」的路線當「長路線」候選（例如東西大縱走橫跨士林、北投、萬里、淡水、三芝五區）。
2. 對每條長路線，先用行政區重疊抓一輪候選（粗篩，跟舊版邏輯一樣）。
3. 對每個候選，抓它自己步道頁裡嵌的官方 GPX（`data-value="https://cdntwrunning.biji.co/hiking_gpx/*.gpx"`），取樣軌跡點，跟長路線的 GPX 算最近距離；候選取樣點裡要有 **50% 以上**落在長路線 **250 公尺**內，才算「真的路過」。
4. 這樣「陽明山東西大縱走」原本行政區重疊法抓出 24 條候選，GPX 精算後剩 6 條真的在路線上的（七星山、大屯山主峰、金包里大路一段、台北大縱走2/3段…），北投溫泉步道、天母運動公園、國立陽明交大這些同區但沒真的路過的健走趣打卡點都被過濾掉了。
5. 沒有官方 GPX 可比對的長路線（少數），前端會退回舊的行政區推測法，並標註「還沒抓 GPX 精算」。

## 已知限制

- 「臺北健走趣」「走路趣尋寶」這類**打卡點/寶石制**活動，官網資料是靠 `nav=` 子頁籤裡零散的活動辦法文字兜出來的路線清單，不一定完整對應到真正需要走的路線；且部分活動（如「山海圳」「樟之細路專區」大分類頁）本身沒有 `trail_list`，抓不到。
- 「附近任務」用縣市中心點比對，不是步道實際座標（官網没在步道頁面直接放經緯度，只有解析後的 GPX 軌跡點），精度只到縣市層級，山區大縣（花蓮、南投）跨鄉鎮時可能不夠準。
- 西班牙朝聖之路（法國之路）路線的「city」欄位是「西班牙」，會被歸進「西班牙朝聖之路－法國之路」活動而非台灣縣市，附近任務查不到很正常。
