# 健行筆記 活動/寶石任務提示（userscript）

站台：`https://hiking.biji.co/*`

## 功能

1. **活動徽章**：步道詳細頁 / 任何頁面上的步道卡片（含 GPX 軌跡頁裡內文引用的步道連結），只要那條路線屬於某個線上活動（寶石任務、尋寶集章、健走趣…），標題旁自動貼徽章，點徽章直接開那條步道自己的頁面（不用往下滑找）。**顏色＝哪個活動**（每個活動固定配色，色相平均分布在色輪上、每色都用同一個 WCAG 亮度目標算出來，全部跟白字對比 ≥7.4:1，不會有某幾色看起來太淡看不到字）；**狀態**（進行中/未開始/已結束/長期）改用透明度、邊框、內縮白邊表示，不吃掉顏色。滑鼠移上去看活動期間。
2. **沿途任務路線**：像「陽明山東西大縱走」這種跨多個行政區的長路線，步道頁/GPX 軌跡頁會多一個可收合面板「🔍 沿途 GPX 軌跡比對，這些任務路線也在路上」，列出實際用官方 GPX 軌跡點算過、真的路過的其他任務路線（見下方「沿途任務路線怎麼算的」）。
3. **附近任務**（右下角「📍 附近任務」按鈕，再按一次收起）：**預設看「當下這一頁步道」附近的進行中任務**——在步道詳細頁直接讀該頁「所在縣市」、在 GPX 軌跡頁用它引用的那條步道（步道不在任務索引裡也行，會同源抓那頁的所在縣市）。結果**由近到遠**排，該步道若有 GPX 精算過的沿途任務路線（🥾 路線上）排最前面，接著同鄉鎮、再來是 10 公里內的鄰近鄉鎮（顯示「約 N 公里」），一次顯示 20 條，按「顯示更多」再展開。距離是鄉鎮中心點之間的距離，僅供參考。沒有步道可參考的頁面（首頁、活動專區…）或想看別的地方，下拉選單可以改選任何鄉鎮市區（照縣市分組），選過的會記住。想用定位也行，面板裡按 📍 才會問權限，抓最近的鄉鎮自動選起來——不按就不會跳定位提示。鄉鎮座標抓自 Nominatim（OpenStreetMap），只在本機比對，不外送任何位置資訊。
4. **去過紀錄彙整**（左下角「✅ 去過紀錄」按鈕）：以 **GPX 軌跡為準**判斷「已去過」——「去過此路線」按鈕是自己手動點的，點過不代表真的去過、沒點也不代表沒去過，站上這個按鈕本身不可靠，只能當參考。真正的「✅ 已去過」只認你自己上傳過的軌跡（見下一點）；寶石任務頁（`q=minisite&id=NNN`）上路線卡片若按鈕顯示已去過但掃不到對應軌跡，貼的是 **⚠️ 按鈕標記，無軌跡**（黃色虛線），提醒你這條可能沒有真的走過、或還沒上傳/掃到軌跡，跟軌跡證實過的 ✅（綠色實線）分開看。逛過的路線會記進本機資料庫，點左下角按鈕開清單，可依 已去過/按鈕標記無軌跡/未去過 篩選、搜尋、匯出 JSON。**這支腳本不會幫你點擊「去過此路線」本身**——按鈕本身還是要自己登入帳號點，這裡純粹只是讀取畫面上目前的狀態做彙整、不碰站上的請求，也不會被判定成代刷。
5. **從「我的軌跡」自動比對**（判斷「已去過」的主要依據）：軌跡標題是站上自動組的「（縣市－）活動名＋路線名＋時間戳」（縣市字首有沒有不一定），拆解、對回路線索引，找得到的直接標記「✅ 已去過」；活動名比對時「臺」「台」視為同一字（站上兩種寫法混用）。
   - **開自己軌跡頁時掃當頁**：`q=member&act=gpx`，只在看得到自己的「刪除」按鈕時才會掃，不會誤讀別人分享頁。
   - **背景自動同步全部分頁**：只要開過一次自己的軌跡頁，腳本就記住你的會員 id，之後在站上**任何一頁**都會背景用 `fetch` 把「我的軌跡」所有分頁抓一輪、自動比對（30 分鐘節流一次，不會每頁都打一輪請求）。上傳新軌跡後不用特地跑回去翻頁。
   - **手動立即同步**：去過紀錄面板裡有「🔄 立即同步軌跡」按鈕，不管節流，馬上抓一次全部分頁；還沒開過自己軌跡頁（不知道會員 id）的話按了會提示你先開一次。
   - 這幾個真實帳號測過（137 筆軌跡）：有清楚對應到目前索引裡路線名稱的抓得到（含跨頁、含縣市字首的變體），自己改過標題（像「天母古道」）或路線屬於已下架/沒收進索引的活動（例如舊一年的健走趣打卡點），沒辦法猜，這種情況本來就沒有夠精確的資料可以自動比對。

## 安裝

Tampermonkey / Violentmonkey 匯入 `biji-event-badge.user.js`。

## 索引怎麼來的

repo 根目錄（`../` 相對這個檔案）底下：

1. `build_index.py` — 爬 `hiking.biji.co` 的活動列表（含分頁與 `category=theme`）與每個活動專區頁（含子頁籤 `nav=`），解析頁面裡的 `<ul id="trail_list">`，產出 `events.json`（活動清單）與 `trails.json`（路線→活動反查表）。
2. `build_overlap.py` — 找出 `trails.json` 裡跨 2 個以上行政區的「長路線」，抓它們自己與候選步道的**官方 GPX**，用軌跡點實際距離（250 公尺內）算是否真的路過，取代單純比對行政區名稱（噪音很大，同區但沒真的路過的健走趣打卡點也會混進來）。有快取（`trail_gpx_cache.json`），中斷重跑不會整個重來。輸出 `overlap.json`。
3. `build_districts.py` — 把 `trails.json` 裡出現過的鄉鎮市區（約 176 個）丟給 Nominatim（OpenStreetMap）查一次真實座標，取代舊版只有 22 縣市中心點的粗略比對。有快取（`districts.json`），查不到座標的（極少數）在 `gen_userscript.py` 退回該縣市中心點，仍然能選、能定位，只是準度粗一點。
4. `gen_userscript.py` — 讀 `events.json` / `trails.json` / `overlap.json` / `districts.json`，壓成 `EV`（活動陣列，含每個活動固定配色）/ `T`（trailId → [名稱,縣市,連結,[活動索引]]）/ `OV`（長路線trailId → GPX確認過的候選trailId清單）/ `DC`（鄉鎮市區座標），貼進 `userscript.tpl.js` 模板，輸出成這支 `biji-event-badge.user.js`，`@version` 自動 +1。
5. `lookup.py` — 純命令列查詢用（不影響 userscript），例：
   ```bash
   python lookup.py 大屯山
   python lookup.py --events
   ```

## 多久要重跑一次

健行筆記活動會換季（例如「2026臺北健走趣」「花蓮山海騎遇記」），新活動上線或路線異動時，重跑：

```bash
cd ..
python build_index.py
python build_overlap.py
python build_districts.py
python gen_userscript.py
```

`build_index.py` 只重抓活動清單本身；`build_overlap.py` / `build_districts.py` 都有快取，只處理還沒出現過的路線/行政區，通常不用整份重跑；只跑 `gen_userscript.py` 也可以（沒有新的 GPX 精算或新地區座標，但 EV/T 索引會更新）。重跑完到 Tampermonkey 重新匯入這支 `.user.js`（`@version` 已自動升號，會被認成新版本更新）。

## 沿途任務路線怎麼算的

1. 從 `trails.json` 抓出「跨 2 個以上行政區」的路線當「長路線」候選（例如東西大縱走橫跨士林、北投、萬里、淡水、三芝五區）。
2. 對每條長路線，先用行政區重疊抓一輪候選（粗篩，跟舊版邏輯一樣）。
3. 對每個候選，抓它自己步道頁裡嵌的官方 GPX（`data-value="https://cdntwrunning.biji.co/hiking_gpx/*.gpx"`），取樣軌跡點，跟長路線的 GPX 算最近距離；候選取樣點裡要有 **50% 以上**落在長路線 **250 公尺**內，才算「真的路過」。
4. 這樣「陽明山東西大縱走」原本行政區重疊法抓出 24 條候選，GPX 精算後剩 6 條真的在路線上的（七星山、大屯山主峰、金包里大路一段、台北大縱走2/3段…），北投溫泉步道、天母運動公園、國立陽明交大這些同區但沒真的路過的健走趣打卡點都被過濾掉了。
5. 沒有官方 GPX 可比對的長路線（少數），前端會退回舊的行政區推測法，並標註「還沒抓 GPX 精算」。

## 已知限制

- 「臺北健走趣」「走路趣尋寶」這類**打卡點/寶石制**活動，官網資料是靠 `nav=` 子頁籤裡零散的活動辦法文字兜出來的路線清單，不一定完整對應到真正需要走的路線；且部分活動（如「山海圳」「樟之細路專區」大分類頁）本身沒有 `trail_list`，抓不到。
- 「附近任務」用鄉鎮市區中心點比對，不是步道實際座標（官網没在步道頁面直接放經緯度，只有解析後的 GPX 軌跡點）；站上把「恆春鎮」寫成「恆春鄉」，Nominatim 查無行政區界，退回該縣市中心點。`build_districts.py` 只收 OSM 行政區界、且查完會檢查不同鄉鎮有沒有拿到同一個座標（有就中止不輸出），因為自由文字查詢曾經把台中市和平區配到新北市。
- 西班牙朝聖之路（法國之路）路線的「city」欄位是「西班牙」，會被歸進「西班牙朝聖之路－法國之路」活動而非台灣縣市，附近任務查不到很正常。
